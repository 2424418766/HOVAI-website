# HOVAI Photography 网站代码交接

这份包提供 HOVAI Photography 作品集网站的前端、后台 API Worker、内置作品数据、图片种子资源、构建脚本和测试脚本。建议交给负责迁移/上线的开发者阅读本说明后再部署。

## 先了解：当前网站依赖原托管环境

这不是可直接拖入任意静态托管后台的一组 HTML 文件。当前版本的后台和媒体接口运行在 Sites Worker 环境，并依赖：

- 一个名为 `BUCKET` 的对象存储绑定，用于持久化 `portfolio.json` 及上传的图片、视频。
- 当前托管平台提供的所有者身份请求头，用于限制后台编辑权限。
- Worker 路由 `/api/portfolio`、`/api/upload`、`/media/*` 和 `/seed/*`。

如果迁移到腾讯云 CloudBase、阿里云或其他国内服务，开发者需要将 Worker API、对象存储绑定和后台身份验证改接到目标平台。仅上传静态页面会丢失后台保存、媒体上传等功能。

## 项目内容

- `src/`：网站页面、样式、交互、Worker 后端、初始作品数据与内置图片资源。
- `scripts/build.mjs`：把源文件构建为 Worker 部署入口。
- `scripts/test*.mjs`：现有功能验证脚本。
- `dist/server/index.js`：已构建的 Worker 入口，供开发者检查/部署。
- `.openai/hosting.json`：原 Sites 项目标识与存储绑定说明；迁移到其他服务时不要把它当作新服务商配置。
- `package.json`：构建与测试命令。

## 本地构建和验证

建议 Node.js 20 或更新版本。在此目录运行：

```bash
npm test
npm run build
```

构建后 Worker 入口位于 `dist/server/index.js`。项目不需要安装额外 npm 依赖。

## 上线前必须迁移的内容

源码中带有建站时整理的初始作品、时装项目导入数据和内置图片。管理员后来在网站后台新增/修改的完整作品目录，以及上传到托管存储里的媒体文件，保存在现有托管环境的对象存储中，不会自动包含在 Git 源码或此压缩包中。

为确保新站与当前线上版本一致，切换前需要由有权限的维护者：

1. 从当前线上环境备份最新作品目录 JSON（`portfolio.json`）。
2. 逐个导出其中 `/media/<UUID>.(jpg|mp4|webm)` 引用的图片、视频，以及视频封面。
3. 将这些媒体导入新服务的对象存储，并由开发者更新/迁移 API 路由和身份校验。
4. 在新服务验证首页、四个 Work 分类、更多案例、视频播放、手机封面、后台编辑/保存、图片上传后，再切换正式域名。

`src/seed.json` 是可运行的初始内容，不应被误认为线上后台当前数据的完整备份。
